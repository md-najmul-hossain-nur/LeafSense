# 🌱 LeafSense – AI Crop Disease Classification

An AI-powered leaf disease detection system that uses a **Convolutional Neural Network (CNN)** to classify plant diseases from leaf images.

## ✨ Features

* CNN-based multi-class leaf disease classification
* PlantVillage dataset with **23 disease classes**
* Image preprocessing and data augmentation
* Confidence-based prediction handling
* Treatment recommendations for detected diseases
* Flask-based web application
* Simple leaf image upload and instant prediction

## 🛠️ Technologies

* Python
* TensorFlow / Keras
* CNN
* Flask
* HTML, CSS & JavaScript
* PIL
* PlantVillage Dataset

## 🔄 Workflow

**Leaf Image → Preprocessing → CNN Model → Disease Prediction → Confidence Check → Treatment Recommendation**

## 📊 Model

The CNN uses **128×128 RGB images** and a 23-neuron softmax output layer for disease classification. The project evaluates performance using Accuracy, Precision, Recall, and F1-score.

## 🎯 Purpose

LeafSense aims to provide farmers and agricultural workers with a quick, accessible, and cost-effective solution for early crop disease detection.
